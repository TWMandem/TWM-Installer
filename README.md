# TWM Installer

**TWM Installer** — установщик для TWM Launcher под Windows. Он позволяет скачать и установить актуальную стабильную версию лаунчера из официального репозитория GitHub.

## Возможности

- Скачивание последней стабильной версии TWM Launcher.
- Проверка SHA-256 загруженного архива.
- Проверка целостности файлов по манифесту `manifest.json`.
- Установка лаунчера в выбранную пользователем папку.
- Запуск установленного лаунчера.
- Удаление лаунчера с возможностью отдельно подтвердить удаление пользовательских данных.

## Официальные репозитории

- **Установщик:** [TWM-Installer](https://github.com/TWMandem/TWM-Installer)
- **Лаунчер и его обновления:** [TWM-Launcher](https://github.com/TWMandem/TWM-Launcher)

Установщик и лаунчер публикуются отдельно. Обновления приложения распространяются через репозиторий `TWM-Launcher`.

## Как работает установка

1. Установщик обращается к GitHub API и получает информацию о последнем стабильном релизе TWM Launcher.
2. Скачивает файлы `latest.json` и `TWM.Launcher.Package.zip`.
3. Сверяет SHA-256 архива со значением в `latest.json`.
4. Проверяет извлечённые файлы по внутреннему манифесту `manifest.json`.
5. Устанавливает файлы лаунчера в выбранную папку.

Для скачивания и проверки пакета требуется подключение к интернету. Если GitHub недоступен или проверка целостности не пройдена, установщик не должен незаметно подменять пакет устаревшей встроенной копией.

## Требования

- Windows.
- Интернет-соединение для загрузки пакета лаунчера.
- Совместимая среда выполнения .NET, включённая в автономную публикацию установщика.
- WebView2 Runtime, если он необходим для работы компонентов лаунчера.

## Сборка из исходного кода

Для сборки проекта необходимы:

- Visual Studio с поддержкой WPF.
- .NET 10 SDK.
- Компоненты Windows Desktop Development.

### Порядок сборки

1. Клонируйте репозиторий.
2. Откройте `TWM.Installer.csproj` в Visual Studio.
3. Выберите конфигурацию `Release`.
4. Настройте профиль публикации для `win-x64`.
5. Выберите автономный режим развертывания (`Self-contained`).
6. Выполните публикацию проекта.

Установщик использует встроенный установщик WebView2. Сам пакет лаунчера загружается из GitHub Releases и не встраивается в установщик.

## Требования к релизу TWM-Launcher

Каждый стабильный релиз, используемый установщиком, должен содержать два файла:

- `TWM.Launcher.Package.zip` — архив файлов лаунчера, содержащий `manifest.json` и каталог `Files/`.
- `latest.json` — JSON-файл с информацией о версии пакета и его контрольной сумме.

Пример структуры `latest.json`:

```json
{
    "packageVersion": "1.0.0",
    "packageFile": "TWM.Launcher.Package.zip",
    "sha256": "REPLACE_WITH_64_HEX_SHA256_OF_THE_ZIP"
}
```

Значение `sha256` должно соответствовать SHA-256 именно того ZIP-архива, который прикреплён к этому релизу. Релиз должен быть опубликован как последний стабильный релиз, а не как черновик или предварительная версия.

## Безопасность пользовательских данных

При удалении лаунчера пользователь отдельно подтверждает, следует ли удалять пользовательские данные, локальные сборки, резервные копии и базу локальных сборок.

Если удаление пользовательских данных не подтверждено, эти данные должны оставаться на компьютере.
